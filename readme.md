# Отчет по лабораторным работам 5, 5.1 и 5.2
## Разработка модульного приложения «Алгоритмическая обработка числовых рядов»

### 1. Введение и цели работы
В рамках выполнения цикла лабораторных работ было разработано модульное консольное приложение на языке Python. 
**Главные цели проекта:**
* Освоить декомпозицию сложной задачи на независимые модули.
* Научиться генерировать числовые ряды (случайные, детерминированные, с шумом).
* Реализовать расчет статистик (среднее, медиана, размах) вручную, без использования сторонних библиотек (`numpy`, `pandas`, `statistics`).
* Реализовать эффективный алгоритм скользящей средней (SMA) через бегущую сумму (сложность O(n)).
* Освоить обработку ошибок (принцип Fail Fast с использованием `raise` и `from err`).
* Настроить CLI (интерфейс командной строки) через модуль `argparse`.

### 2. Архитектура и структура проекта
Проект разделен на независимые модули, каждый из которых отвечает за свою зону ответственности:

```text
.
├── num_series/                  # Пакет с основной логикой
│   ├── __init__.py              # Экспорт публичного API пакета
│   ├── generator.py             # Генерация рядов (random, sine, trend, two_harmonics)
│   ├── stats.py                 # Статистики (mean, median, spread) и поиск экстремумов
│   ├── moving_average.py        # Скользящие средние (SMA, CMA, EMA) и бенчмарк
│   ├── deque_average.py         # Скользящие средние на базе collections.deque
│   ├── io_json.py               # Сохранение/чтение JSON с метаданными
│   └── io_file.py               # Чтение TXT и CSV файлов
├── tests/                       # Пакет с автотестами (ЛР 5.2)
│   ├── conftest.py              # Настройка путей pytest
│   ├── test_generator.py        # Тесты генераторов
│   ├── test_stats.py            # Тесты статистик
│   ├── test_moving_average.py   # Тесты SMA, CMA, EMA
│   ├── test_deque_average.py    # Дифференциальные тесты (list vs deque)
│   ├── test_io_json.py          # Тесты JSON
│   ├── test_io_file.py          # Тесты TXT/CSV
│   └── test_cli.py              # Интеграционные тесты CLI
├── main.py                      # Точка входа CLI (оркестрация)
├── pytest.ini                   # Конфигурация pytest
├── run_self_tests.py            # Скрипт проверки без pytest
└── README.md                    # Отчет (этот файл)
